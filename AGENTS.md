## Baseline rules

- Treat the repository and its documentation as the source of truth.
- Keep documentation updated with behavior, architecture, and workflow changes.
- Never commit credentials, tokens, private media, or machine-local agent settings.
- Prefer small, reviewable changes and run the relevant checks before handoff.
- Do not invent product requirements or select a technology stack without recording the decision.

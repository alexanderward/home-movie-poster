# Movie-night scheduling

The phone UI searches TMDB and saved presentation records, accepts any date and optional local showtime, and offers a next-Friday shortcut. Only one event may occupy a local calendar date. Past events archive after local midnight; the nearest future event is advertised when playback is idle.

Scheduling snapshots only the title, year, and poster needed for presentation. Deletion removes the event but retains that small presentation record for history and reuse.

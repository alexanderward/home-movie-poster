# UI reference study

This directory records the implementation study used by the React client. The canonical design tokens and behaviors live in `DESIGN.md` and `apps/client/src/styles.css`.

- `display.html` studies the portrait marquee hierarchy and uncropped poster region.
- `admin.html` studies the compact phone cards, schedule queue, and form controls.

These static files contain no API behavior and are not shipped in the production image.
